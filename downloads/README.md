# Aggiornare Crypto City

Se Crypto City funziona già sul tuo PC, scarica
[Crypto-City-INTERFACCIA.zip](Crypto-City-INTERFACCIA.zip) con **Download raw**.

1. Scegli **Estrai tutto**.
2. Copia la cartella `dashboard` estratta dentro la cartella del progetto, dove ci sono
   `APRI_CRYPTO_CITY.cmd`, `dashboard`, `engine` e `state`.
3. Accetta **Sostituisci i file nella destinazione**.
4. Nella città aperta nel browser premi **Ctrl+F5**.

Il pacchetto aggiorna esclusivamente nove file dell'interfaccia: nome Crypto City,
logo CC, menu, configurazione AI e app installabile. Motore, server, stato e dati
personali non sono inclusi. Il server già avviato può restare aperto.

Per una prima installazione scarica invece la repository completa con
**Code → Download ZIP** e segui il README principale.

I pacchetti `Crypto-City-START.zip`, `Crypto-City-START-FIX.zip`,
`crypto-city-update.zip` e `crypto-city-update-v2.zip` conservano gli installatori
precedenti per compatibilità. La pagina inclusa è aggiornata, ma questi installatori
copiano soltanto `index.html`: per aggiornare anche nome e icone dell'app usa la ZIP
dell'interfaccia indicata sopra.
