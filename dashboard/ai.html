Configura il cervello della Crypto Machine

Crea le API key nelle console ufficiali, poi salvale qui come GitHub Actions Secrets. L'orchestratore scopre modelli, quote e disponibilità e può passare automaticamente a provider o chiavi alternative.

🔐 Sicurezza: le key non vengono salvate nel browser o nel repository. La plancia le invia al server, che le cifra con la chiave pubblica GitHub prima di salvarle come secret.

Per aumentare la capacità puoi aggiungere PROVIDER_API_KEY_1, _2, ecc. Non incollare mai una key in issue, commit o file.
